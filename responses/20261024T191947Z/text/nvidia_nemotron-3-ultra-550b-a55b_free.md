## Introduction  

Grant writing is **both an art and a science**. The “art” lives in storytelling—making a funder feel the urgency of your mission and the promise of your solution. The “science” lives in data, logic models, budgets, and compliance. Nonprofits that master both win more awards, retain funders longer, and scale impact faster.  

This guide walks you through **seven phases** of the grant lifecycle, each broken into concrete steps, real‑world examples, and printable checklists you can paste into a project‑management tool (Asana, Trello, Monday.com, or a simple Google Sheet).  

> **Who should read this?**  
> * Executive Directors & Development Directors who oversee the grant pipeline.  
> * Grant writers (staff or consultants) who draft proposals.  
> * Program managers who supply logic‑model and budget data.  
> * Finance staff who ensure budget compliance.

## Phase 1 – Know the Landscape: Researching Funders  

### 1.1 Define Your Funding Priorities  

| Question | Why It Matters | Example Answer |
|----------|----------------|----------------|
| What program(s) need funding? | Aligns research to actual need. | “Youth‑STEM after‑school program – $150k/yr.” |
| What geographic focus? | Many funders restrict to city, state, region. | “Greater Chicago metro area.” |
| What type of support? | Operating, capital, capacity‑building, seed, multi‑year. | “3‑year program grant + 1‑year capacity‑building.” |
| What is the ideal grant size? | Prevents wasting time on too‑small or too‑large opportunities. | “$75k–$250k per year.” |

**Action:** Create a **Funding Priorities Matrix** (one‑page) and share it with the whole development team.  

### 1.2 Build a Funder Database  

| Source | Frequency | Key Fields to Capture |
|--------|-----------|-----------------------|
| Foundation Directory Online (FDO) | Weekly | Name, focus areas, geographic limits, typical grant size, deadline, contact, 990‑PF data |
| GrantStation / Instrumentl | Daily alerts | New RFP, rolling deadlines, eligibility notes |
| Local community foundations | Quarterly | Regional priorities, board members |
| Corporate giving pages | Monthly | CSR focus, employee‑matching, in‑kind |
| Government (Grants.gov, SAM.gov) | Daily | CFDA number, eligibility, cost‑share |
| Philanthropy newsletters (e.g., Chronicle of Philanthropy) | Weekly | Trend articles, new initiatives |

**Tip:** Use a **single master spreadsheet** (or Airtable base) with a “Status” column: *Prospect → Qualified → Cultivated → Submitted → Awarded/Declined*.  

### 1.3 Qualify Funders with a **Fit Scorecard**  

| Criterion (Weight) | Score 1‑5 | Weighted Score |
|--------------------|----------|----------------|
| Mission alignment (30%) |  |  |
| Geographic match (15%) |  |  |
| Grant size fit (15%) |  |  |
| Funding type match (10%) |  |  |
| Decision‑maker accessibility (10%) |  |  |
| Historical giving to similar orgs (10%) |  |  |
| Application complexity vs. capacity (10%) |  |  |
| **Total** |  | **/5** |

**Rule of thumb:** Pursue only funders scoring **≥3.5**.  

### 1.4 Deep‑Dive Research (The “Funders’ DNA”)  

1. **Read the last 3‑5 years of 990‑PFs** – note grant amounts, recipients, trends.  
2. **Scan annual reports, website, social media** – look for language they use (“equity‑centered,” “systems change”).  
3. **Identify the program officer** – LinkedIn, foundation staff page, conference speaker lists.  
4. **Map the funder’s “theory of change”** – many foundations publish a logic model; mirror its terminology.  

**Concrete Example**  
*The **Kresge Foundation**’s “Health Equity” portfolio emphasizes “community‑driven solutions” and “policy advocacy.”*  
- **Your language:** “Our project is community‑driven, co‑designed with resident advisory boards, and includes a policy‑brief component to scale impact.”  

### 1.5 Cultivation Before the Ask  

| Activity | Timing | Owner |
|----------|--------|-------|
| Send a brief “impact snapshot” (1‑page) | 6‑12 months before deadline | Development Director |
| Invite program officer to site visit / virtual tour | 4‑6 months | ED + Program Manager |
| Share relevant media coverage / evaluation brief | Ongoing | Communications |
| Attend funder’s public events (webinars, grantee convenings) | As scheduled | All staff |

**Checklist – Funder Research & Qualification**  

- [ ] Funding Priorities Matrix completed.  
- [ ] Master funder database updated (last 30 days).  
- [ ] Fit Scorecard run for each new prospect.  
- [ ] 990‑PF & annual report reviewed for top 10 prospects.  
- [ ] Program officer contact identified & logged.  
- [ ] Cultivation plan drafted (touchpoints, dates, owners).

## Phase 2 – Build a Winning Narrative  

### 2.1 The Core Components of a Grant Narrative  

| Section | Purpose | Typical Length |
|---------|---------|----------------|
| **Cover Letter** | Human connection; reference prior contact. | 1 page |
| **Executive Summary** | Stand‑alone snapshot; decision‑makers often read only this. | ½–1 page |
| **Statement of Need / Problem Statement** | Evidence‑based urgency. | 1–2 pages |
| **Project Description (Goals, Objectives, Activities, Timeline)** | What you’ll do, how, when. | 3–5 pages |
| **Organizational Capacity** | Credibility, track record, staff. | 1–2 pages |
| **Evaluation Plan** | How you’ll measure success. | 1–2 pages |
| **Sustainability / Future Funding** | Post‑grant viability. | ½–1 page |
| **Budget Narrative** | Narrative justification for each line item. | 1–2 pages |
| **Attachments** | IRS 501(c)(3) letter, audited financials, board list, letters of support. | As required |

### 2.2 Crafting a Compelling **Needs Statement**  

**Formula:**  

```
[Population] + [Geography] + [Problem] + [Data] + [Gap] = Need
```

**Step‑by‑Step Example**  

| Element | Draft |
|---------|-------|
| Population | “Low‑income, first‑generation high‑school students” |
| Geography | “South Side Chicago (zip codes 60619, 60620, 60621)” |
| Problem | “Only 38 % graduate on time; 62 % lack access to STEM enrichment.” |
| Data | “Chicago Public Schools 2023 Report; U.S. Census ACS 2022.” |
| Gap | “Existing after‑school programs serve <10 % of eligible youth; none integrate college‑ready STEM curriculum.” |
| **Resulting Need Statement** | “In South Side Chicago, 62 % of low‑income, first‑generation high‑school students lack access to STEM enrichment, contributing to a 38 % on‑time graduation rate. Current after‑school capacity reaches fewer than 10 % of eligible youth, leaving a critical gap in college‑ready STEM pathways.” |

**Tips**  

- **Lead with the human story** (a 2‑sentence vignette).  
- **Use “because”** to link cause → effect.  
- **Cite 2‑3 high‑credibility sources** (government, peer‑reviewed, reputable nonprofit).  
- **Avoid jargon**; funders read many proposals.  

### 2.3 Writing SMART Objectives  

| Component | Example |
|-----------|---------|
| **Specific** | “Increase the number of students completing a hands‑on robotics module.” |
| **Measurable** | “From 0 to 120 students per year.” |
| **Achievable** | “Based on current staff capacity (2 STEM instructors) and partner space.” |
| **Relevant** | “Directly supports the goal of raising STEM college‑readiness.” |
| **Time‑bound** | “By June 30, 2026 (end of Year 2).” |

**Template**  

> **Objective 1:** By **[date]**, **[target population]** will **[action verb]** **[quantifiable outcome]**, as measured by **[indicator]**.  

### 2.4 Storytelling Techniques  

| Technique | How to Apply |
|-----------|--------------|
| **“Hero’s Journey”** | Position the community as the hero; your org is the guide. |
| **Data‑Story Sandwich** | Data → Human anecdote → Data. |
| **“So What?” Test** | After each paragraph ask: *So what? Why does the funder care?* |
| **Active Voice** | “We will train…”, not “Training will be provided.” |
| **Visual Hooks** | Insert a 1‑sentence “impact snapshot” box (e.g., “120 youth served, 85 % report increased STEM confidence”). |

### 2.5 Organizational Capacity – Show, Don’t Just Tell  

| Evidence | Format |
|----------|--------|
| **Track record** | Table of past grants (funder, amount, outcomes). |
| **Staff bios** | 2‑line bullets: name, title, relevant experience, % FTE on project. |
| **Governance** | Board matrix (skills, demographics, giving). |
| **Partnerships** | MOUs, letters of support, joint‑venture agreements. |
| **Financial health** | Current ratio, unrestricted net assets, audit opinion. |

**Example Capacity Paragraph**  

> “Since 2015, **STEM Pathways Chicago** has secured $3.2 M in multi‑year grants (MacArthur, Chicago Community Trust, NSF). Our 2022 audit received an unmodified opinion; unrestricted net assets equal 6 months of operating expenses. The project will be led by Dr. Maya Patel (PhD, Mechanical Engineering, 12 yr nonprofit STEM program management) at 0.75 FTE, supported by two certified STEM instructors (1.0 FTE each) and a data analyst (0.5 FTE).”

### 2.6 Evaluation Plan – From Outputs to Outcomes  

| Level | Definition | Example Indicator | Data Source | Frequency |
|-------|------------|-------------------|-------------|-----------|
| **Outputs** | Direct products/services | # of robotics workshops delivered | Program calendar | Quarterly |
| **Short‑term Outcomes** | Changes in knowledge/attitude | % youth reporting ↑ STEM confidence (pre/post survey) | Survey (validated) | Pre, post, 6‑mo follow‑up |
| **Intermediate Outcomes** | Behavior change | % youth enrolling in AP STEM courses | School enrollment data | Annually |
| **Long‑term Impact** | Systemic change | ↑ on‑time graduation rate in target zip codes | CPS graduation reports | 3‑yr lag |

**Evaluation Design Checklist**  

- [ ] Logic model linked to each objective.  
- [ ] At least one **validated instrument** (e.g., STEM Attitude Survey).  
- [ ] **Comparison group** or **pre‑post** design described.  
- [ ] Data‑collection timeline aligned with reporting deadlines.  
- [ ] **IRB** consideration noted (if human subjects).  
- [ ] **Budget line** for evaluation (typically 5‑10 % of total).

## Phase 3 – Design a Rigorous Program Logic  

### 3.1 Logic Model vs. Theory of Change  

| Feature | Logic Model | Theory of Change |
|---------|-------------|------------------|
| **Scope** | One program/project | Whole organization or system |
| **Visual** | Table/flowchart (Inputs → Activities → Outputs → Outcomes → Impact) | Narrative + diagram, often with assumptions & context |
| **Use** | Grant proposals, internal monitoring | Strategic planning, funder alignment |

**Best practice:** **Develop both**. The logic model satisfies the grant’s “program design” section; the theory of change lives in your strategic plan and helps you articulate *why* the logic model works.  

### 3.2 Building a Logic Model – Step‑by‑Step  

| Column | Prompt | Example (STEM After‑School) |
|--------|--------|-----------------------------|
| **Inputs** | Resources you need | $150k grant, 2 STEM instructors, 1 data analyst, partner school space, laptops, curriculum kits |
| **Activities** | What you’ll do | Recruit 120 youth; deliver 30 weekly 2‑hr robotics workshops; host 2 family STEM nights; provide college‑application coaching |
| **Outputs** | Tangible counts | 120 youth enrolled; 30 workshops; 2 family nights; 120 college‑app essays reviewed |
| **Short‑Term Outcomes** | Immediate changes | 85 % youth report ↑ STEM confidence; 90 % complete at least 1 robotics project |
| **Intermediate Outcomes** | Behavior/skill changes | 60 % enroll in AP STEM; 70 % submit FAFSA |
| **Long‑Term Impact** | Systemic change | 10 % increase in on‑time graduation in target zip codes within 5 yr |

**Visual Tip:** Use **Lucidchart, Miro, or PowerPoint SmartArt** – keep it one page, landscape.  

### 3.3 Embedding Assumptions & External Factors  

| Assumption | Risk if False | Mitigation |
|------------|---------------|------------|
| Schools will allocate classroom space. | No venue → workshops cancel. | MOUs signed 3 months prior; backup community‑center space identified. |
| Youth attendance ≥80 % per session. | Low dosage → weaker outcomes. | Incentive stipends ($10/session), transportation vouchers, parent engagement calls. |
| Curriculum aligns with state STEM standards. | Credibility loss with schools. | Curriculum vetted by CPS STEM coordinator; annual review. |

### 3.4 Linking Logic Model to Budget  

| Logic Model Row | Budget Line(s) | % of Total |
|-----------------|----------------|------------|
| Instructors (2 FTE) | Personnel – Salaries & Benefits | 38 % |
| Laptops & Kits | Equipment & Supplies | 12 % |
| Family Nights | Events & Outreach | 5 % |
| Data Analyst (0.5 FTE) | Personnel – Evaluation | 8 % |
| Evaluation Instruments | Consultants / Survey Tools | 4 % |
| Indirect Costs (10 % MTDC) | Overhead | 10 % |
| **Total** |  | **100 %** |

## Phase 4 – Craft a Transparent, Realistic Budget  

### 4.1 Budget Structure (Standard Federal & Foundation Format)  

| Category | Typical Sub‑Lines | % of Total (Rule‑of‑Thumb) |
|----------|-------------------|----------------------------|
| **Personnel** | Salaries, fringe, %FTE | 40‑55 % |
| **Fringe Benefits** | Health, retirement, payroll tax | 15‑25 % of personnel |
| **Travel** | Local mileage, conference travel | 2‑5 % |
| **Equipment** | >$5k unit cost, depreciation | 3‑8 % |
| **Supplies** | Consumables, curriculum kits | 3‑7 % |
| **Contractual / Consultants** | Evaluation, legal, tech | 5‑15 % |
| **Other Direct Costs** | Space rental, printing, incentives | 2‑6 % |
| **Indirect Costs (IDC)** | % of Modified Total Direct Costs (MTDC) | 8‑15 % (or funder‑specified) |
| **Total** |  | 100 % |

### 4.2 Budget Narrative – The “Why” Behind Every Number  

**Template (per line item)**  

> **Line Item:** *Senior STEM Instructor (1.0 FTE)*  
> **Amount:** $68,000 (salary $55,000 + fringe $13,000)  
> **Justification:** *Responsible for curriculum delivery, student mentorship, and data collection. Salary based on 2023 Chicago nonprofit market rate (BLS OES 25‑2021). Fringe at 23 % per organizational policy.*  

**Do’s & Don’ts**  

| Do | Don’t |
|----|-------|
| Tie each cost to a logic‑model activity. | Lump “miscellaneous” >5 % of total. |
| Show **cost‑share** or **in‑kind** contributions (e.g., school space valued at $12k). | Inflate salaries beyond market. |
| Use **realistic fringe rates** (audit‑approved). | Forget to include **travel for site visits** if required. |
| Provide **unit cost × quantity** for supplies. | Use round numbers without backup. |

### 4.3 Common Budget Pitfalls & Fixes  

| Pitfall | Fix |
|---------|-----|
| **Over‑budgeting personnel** (e.g., 1.5 FTE for a 0.75 FTE role). | Align FTE to activity calendar; use part‑time rates. |
| **Missing indirect cost rate** (funder caps at 10 % but you budget 15 %). | Negotiate a **Negotiated Indirect Cost Rate Agreement (NICRA)** or use funder’s cap. |
| **No contingency** for price inflation. | Add 2‑3 % contingency line (label “Contingency – price escalation”). |
| **In‑kind not valued** (e.g., volunteer hours). | Assign fair‑market value; document with volunteer logs. |
| **Budget not reconciled to narrative** (numbers differ). | Run a **cross‑walk** spreadsheet before final PDF. |

## Phase 5 – Assemble a Polished Proposal Package  

### 5.1 Formatting & Style Consistency  

| Element | Standard |
|---------|----------|
| **Font** | 11‑pt Calibri / Arial / Times New Roman (per funder). |
| **Margins** | 1‑inch all sides. |
| **Headers/Footers** | Org name, grant title, page #. |
| **File Naming** | `OrgName_GrantName_YYYYMMDD_v1.pdf` |
| **PDF/A‑1b** | For archival compliance (many gov. portals). |
| **Accessibility** | Tagged PDF, alt‑text for images, readable contrast. |

### 5.2 Required Attachments Checklist  

| Attachment | Typical Requirement | Tips |
|------------|--------------------|------|
| IRS 501(c)(3) determination letter | All foundations & gov. | Keep a scanned copy (PDF) in a shared drive. |
| Audited financial statements (last 2 yr) | Most funders | Highlight unrestricted net assets. |
| Board of Directors list (with affiliations) | Many | Include diversity metrics if funder asks. |
| Organizational chart | Some | Show program staff vs. admin. |
| Letters of Support / MOUs | Often 2‑3 | Get on letterhead, signed, dated ≤6 months. |
| Key Staff résumés / bios | Usually 1‑page each | Tailor to project relevance. |
| Evaluation instruments (survey, rubric) | If requested | Attach as appendix, not in narrative. |
| Current strategic plan (excerpt) | Occasionally | 1‑page summary of alignment. |

### 5.3 Internal Review Process (The “Red‑Team” Review)  

| Reviewer | Focus | Deadline (relative to submission) |
|----------|-------|-----------------------------------|
| **Program Lead** | Logic model fidelity, activity feasibility | T‑14 days |
| **Finance Director** | Budget accuracy, compliance, indirect rate | T‑12 days |
| **Development Director** | Narrative alignment with funder priorities | T‑10 days |
| **Executive Director** | Overall strategic fit, risk | T‑7 days |
| **External Peer (optional)** | Fresh eyes, clarity | T‑5 days |
| **Final Proofread** | Grammar, formatting, file naming | T‑2 days |

**Tool:** Use **Google Docs “Suggesting” mode** or **Microsoft Word Track Changes**; compile comments in a single “Review Log” spreadsheet.  

### 5.4 Submission Mechanics  

| Portal | Key Steps |
|--------|-----------|
| **Grants.gov** | Register SAM.gov → Create Workspace → Upload PDFs → Validate → Submit (receive tracking #). |
| **Foundation Online Portal** | Create account → Fill forms → Upload attachments → Click “Submit”. |
| **Email** | PDF + cover letter in body; request read‑receipt; follow up with phone call. |
| **Hard Copy** | Print double‑sided, bind, include cover sheet; mail certified with tracking. |

**Pro Tip:** **Submit 48 hours before deadline** to avoid last‑minute technical glitches.

### 6.2 Post‑Submission Communication  

| Timing | Action |
|--------|--------|
| **Day 0** | Send thank‑you email to program officer (reference submission ID). |
| **Week 2** | If no acknowledgement, polite follow‑up (phone/email). |
| **Decision Day** | Respond within 24 hrs – thank you (if awarded) or request feedback (if declined). |
| **Awarded** | Sign grant agreement, return required docs (W‑9, insurance). |
| **Declined** | Add to “Declined – Feedback” tab; schedule debrief with program officer (if offered). |

### 6.3 Managing Multiple Simultaneous Proposals  

- **Capacity Rule:** No more than **3 full‑time proposals** per grant writer at once.  
- **Color‑Code** dashboard: Green (on track), Yellow (needs data), Red (at risk).  
- **Weekly 30‑min “Grant Stand‑Up”** with all writers to surface bottlenecks.

## Phase 7 – Post‑Award Management & Reporting  

### 7.1 Grant Agreement Review Checklist  

| Item | Verify |
|------|--------|
| **Award amount & payment schedule** | Matches proposal; note any cost‑share. |
| **Allowable vs. unallowable costs** | Cross‑check with budget narrative. |
| **Reporting frequency & format** | Quarterly narrative + financial; annual audit. |
| **Indirect cost rate** | Confirmed (NICRA or funder cap). |
| **Compliance clauses** | Lobbying, human subjects, sub‑award monitoring. |
| **Amendment process** | Written request, 30‑day notice. |
| **Close‑out requirements** | Final report, financial reconciliation, equipment disposition. |

### 7.2 Financial Management  

| Process | Tool | Frequency |
|---------|------|-----------|
| **Expense tracking** | QuickBooks / Sage Intacct (grant‑specific class) | Real‑time |
| **Drawdown requests** | Funder portal or invoice template | Per payment schedule |
| **Reconciliation** | Compare ledger to budget line items | Monthly |
| **Audit prep** | Maintain grant‑level trial balance | Ongoing |
| **Cost‑share documentation** | In‑kind logs, volunteer hours, partner invoices | Quarterly |

**Tip:** Create a **“Grant Budget vs. Actual”** variance report (Excel pivot) for each board meeting.  

### 7.3 Programmatic Monitoring  

| Indicator | Data Source | Collection Method | Responsible | Reporting Cadence |
|-----------|-------------|-------------------|-------------|-------------------|
| # youth enrolled | Enrollment database | Auto‑export CSV | Program Coordinator | Monthly |
| Workshop attendance | Sign‑in sheets (digital) | Tablet app | Instructors | Weekly |
| STEM confidence (pre/post) | SurveyMonkey (validated) | Online link | Evaluator | Pre, post, 6‑mo |
| AP STEM enrollment | School district data share | Data‑use agreement | Data Analyst | Annually |
| Graduation rate | CPS public reports | Public download | Evaluator | 3‑yr lag |

**Dashboard:** Build a **Power BI / Tableau** dashboard (or Google Data Studio) that auto‑refreshes from the above sources. Share read‑only link with funder (if permitted).  

### 7.4 Narrative Reporting – Structure & Style  

| Section | Content | Length |
|---------|---------|--------|
| **Executive Summary** | High‑level progress, key wins, any deviations. | ½ page |
| **Activities Completed** | Map to logic model activities; note any changes. | 1–2 pages |
| **Outcomes & Data** | Tables + brief interpretation; highlight statistical significance. | 1–2 pages |
| **Challenges & Adaptations** | Transparent, solution‑focused. | ½ page |
| **Financial Summary** | Budget vs. actual, variance explanations. | ½ page |
| **Next Steps** | Upcoming activities, any budget reallocations. | ½ page |
| **Attachments** | Updated logic model, evaluation instruments, photos (with consent). | As needed |

**Writing Tips**  

- Use **“We”** for organizational actions, **“The program”** for outcomes.  
- Quantify: “Attendance rose 12 % (from 85 to 95 youth)”.  
- Include **quotes** from participants (with permission).  
- Flag **any budget reallocations >10 %** with a brief justification.  

### 7.5 Close‑Out Package  

| Document | Due |
|----------|-----|
| Final Narrative Report | 30 days after grant end |
| Final Financial Report (SF‑425 or funder form) | 30 days |
| Equipment Disposition Form | 30 days |
| Audit (if required) | Per funder timeline (often 90 days) |
| Thank‑You / Impact Letter to Funder | 15 days after close‑out |

## Quick‑Reference Checklists  

### A. Pre‑Proposal (Research & Qualification)  
- [ ] Funding Priorities Matrix completed.  
- [ ] Master funder database updated (last 30 days).  
- [ ] Fit Scorecard run for each new prospect.  
- [ ] 990‑PF & annual report reviewed for top 10 prospects.  
- [ ] Program officer contact identified & logged.  
- [ ] Cultivation plan drafted (touchpoints, dates, owners).  

### B. Narrative Development  
- [ ] Needs statement follows **Population + Geography + Problem + Data + Gap** formula.  
- [ ] All objectives are **SMART** and linked to logic model.  
- [ ] Organizational capacity paragraph includes **track record, staff bios, governance, partnerships, financial health**.  
- [ ] Evaluation plan covers **outputs, short‑term, intermediate, long‑term** with indicators, sources, frequency.  
- [ ] Narrative passes **“So What?” test** for each paragraph.  

### C. Logic Model & Theory of Change  
- [ ] One‑page logic model (Inputs → Activities → Outputs → Outcomes → Impact).  
- [ ] Theory of Change narrative with assumptions & external factors.  
- [ ] Each logic‑model row mapped to a budget line.  

### D. Budget  
- [ ] Budget follows standard categories; totals match narrative.  
- [ ] Budget narrative justifies **every line** (unit cost × qty, market rate, %FTE).  
- [ ] Indirect cost rate confirmed (NICRA or funder cap).  
- [ ] In‑kind contributions valued & documented.  
- [ ] Contingency line (2‑3 %) included.  

### E. Proposal Assembly  
- [ ] Formatting per funder specs (font, margins, PDF/A).  
- [ ] All required attachments collected, signed, dated ≤6 months.  
- [ ] Internal review log completed (program, finance, development, ED, peer).  
- [ ] Final PDF named per convention; uploaded to portal 48 hrs before deadline.  

### F. Post‑Submission  
- [ ] Thank‑you email sent Day 0.  
- [ ] Tracking dashboard updated with status, deadlines, contacts.  
- [ ] Calendar reminders set for reporting dates.  

### G. Post‑Award Management  
- [ ] Grant agreement reviewed against checklist.  
- [ ] Grant‑specific class set up in accounting system.  
- [ ] Monitoring dashboard built (program + financial).  
- [ ] Quarterly narrative & financial reports drafted per template.  
- [ ] Close‑out package prepared 30 days before grant end.
