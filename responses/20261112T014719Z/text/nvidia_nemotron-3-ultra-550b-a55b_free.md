SECTION 2: CRAFTING A COMPELLING NEEDS STATEMENT
LINE 18: Start with a clear problem definition supported by data.
LINE 19: Example: “In County X, 27 % of children ages 0‑5 live in food‑insecure households (USDA 2023).”
LINE 20: Use both quantitative (statistics, rates) and qualitative (stories, testimonials) evidence.
LINE 21: Cite reputable sources: government reports, peer‑reviewed studies, local health department data.
LINE 22: Explain why the problem persists despite existing services.
LINE 23: Highlight the specific population you will serve (age, geography, demographics).
LINE 24: Connect the need to the funder’s stated priorities.
LINE 25: Keep the narrative concise – 250‑350 words for most applications.
LINE 26: Avoid jargon; write for a non‑technical reviewer.
LINE 27: Use a “problem‑solution” framing: problem → gap → your unique approach.
LINE 28: Include a brief “theory of change” sentence linking need to expected outcomes.

SECTION 3: DEVELOPING PROGRAM DESIGN AND LOGIC MODEL
LINE 37: Begin with a logic model template: Inputs → Activities → Outputs → Outcomes → Impact.
LINE 38: Inputs: staff, volunteers, facilities, technology, partnerships, budget.
LINE 39: Activities: workshops, home visits, mobile pantry routes, advocacy campaigns.
LINE 40: Outputs: number of sessions delivered, meals distributed, families reached.
LINE 41: Short‑term outcomes: increased knowledge of nutrition, improved food access.
LINE 42: Intermediate outcomes: reduced food‑insecurity scores, higher school attendance.
LINE 43: Long‑term impact: healthier child development, reduced healthcare costs.
LINE 44: Use SMART criteria for each outcome (Specific, Measurable, Achievable, Relevant, Time‑bound).
LINE 45: Example outcome: “By month 12, 80 % of participating families will report a 15 % increase in household food security (USDA HFSSM).”
LINE 46: Map each activity to at least one output and one outcome.
LINE 47: Identify assumptions and external factors (e.g., policy changes, economic shifts).
LINE 48: Visualize the model in a one‑page diagram for quick reviewer reference.

LINE 77: Use the funder’s budget template; if none, follow the standard categories: Personnel, Fringe, Travel, Equipment, Supplies, Contractual, Other, Indirect.
